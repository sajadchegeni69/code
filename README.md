# Aamoza Generated Android Project

This repository is generated and maintained by Aamoza. The Android project lives at the repository root.

## Build

Use the Gradle Wrapper when the wrapper JAR is present:

```bash
./gradlew assembleDebug
```

The included GitHub Actions workflow can bootstrap Gradle on CI when a wrapper JAR is not available in a browser-generated project.

## Project metadata

Aamoza metadata is stored under `.aamoza/`.
